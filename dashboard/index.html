    Connect the published report

    1. Open powerbi/MumbaiHealth.pbip in Power BI Desktop and click Refresh.
    2. Click Publish and choose a workspace.
    3. In the Power BI service, open the report and choose File → Embed report → Publish to web (public). Copy the link that starts with https://app.powerbi.com/view?r=.
    4. Paste it into dashboard/powerbi-config.js as embedUrl, save, and reload this page.

    Full steps, including what to do if your organisation blocks Publish to web, are in powerbi/POWERBI_GUIDE.md.
