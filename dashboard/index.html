    Ward table

    Exploratory model. K-Means (K = 4) on 24 wards using four category rates per 100k (log1p, standardized). Clusters describe how similar the listed-facility mix is across wards, not whether access is adequate. Mean silhouette 0.316. Results change with the feature set; see the model card.
